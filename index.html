MANUAL:

Este é um manual básico sobre tags HTML.

Obs: Aqui voçê encontrará apenas as tags mais comuns.

Tags de cabeçalho / Título

Vamos começar com as tags de cabeçalho, que são usadas para criar títulos e subtitulos em uma página web. Os niveis de cabeçalho vão de h1 a h6,sendo h1 o titulo, h2 o subtitulo, o h3 significa que esse é um sub-assunto do h2 qu esta acima dele. E assim sucessivamente, até o h6.

Tag para criar um linha horizontal

A tag <hr> é utilizada para criar uma linha horizontal na página web. É muito utilizada para separar conteúdos de texto.

Tag para criar uma quebra de linha

A tag <br> é utilizada para criar uma quebra de linha na página web, por exemplo: Olá,
como você está?

(O espaço foi criado entre o Olá e o como você está)?

Tag para adicionar um link de um site e etc...

A tag <a> é utilizada para criar um link para outro site, ou até mesmo para outra página do mesmo site. Para isso, é necessário utilizar o atributo href, que indica o endereço do link. Exemplo:
<a href="https://www.google.com">Google</a>

Tag para usar simbolos

Para usar símbolos em HTML 5 é bem simples,basta utilizar &...;

Adicionar emojis

Texto excluido:

Tag: <del>
ex: texto

Texto Inserido:

Tag: <ins>
ex: texto

Texto sobrescrito:

Tag: <sup>
ex: x20+3

Texto subscrito:

Tag: <sub>
ex: H2O

Adicionar emojis 🙃:

Para adicionar emojis, utilize o código do emoji que corresponde a ele, para achar o emoji e o código, você pode usar o site "emojipedia" ou "https://getemoji.com/".

Depois basta utilizar a tag <&#x...;> com o código do emoji.

Exemplo: &#x (codigo do emoji);
